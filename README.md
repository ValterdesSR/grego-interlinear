# grego-interlinear
Tradução Interlinear da Bíblia Grega Nestle 1904

Este é um trabalho voluntário, abnegado e dedicado na produção de uma versão Interlinear da Bíblia Sagrada com base no texto Nestle 1904.

Sua reprodução será permitida somente com a devida autorização.

Sugestões de melhorias serão apreciadas no e-mail interlinearnestle@gmail.com
